### 步骤 3：配置权限

```
用户: 我已经创建了应用，接下来怎么配置权限？
```

**Beeclaw 会**:
1. ✅ 告诉你需要哪些权限
2. ✅ 解释每个权限的作用
3. ✅ 指导配置步骤

**预期回复**:
```
Beeclaw: 需要配置以下权限：

在"权限管理"页面添加：

✅ 必需权限:
1. im:message - 获取与发送消息
2. im:message:send_as_bot - 以应用身份发消息
3. im:chat - 获取群组信息

🔧 可选权限（推荐）:
4. im:message.group_msg - 接收群聊消息
5. contact:user.base - 获取用户基本信息

配置完成后，点击"发布版本"使权限生效。

配置好了告诉我，我会启动 Bot。
```

## 常见问题

### Q1: Bot 没有回复消息？

**A**: Beeclaw 会帮你诊断：
```
用户: Bot 没有回复，帮我检查问题
```

Beeclaw 会：
1. 检查连接状态
2. 验证权限配置
3. 查看错误日志
4. 提供解决方案

### Q2: 如何让 Bot 只在特定群工作？

**A**: 告诉 Beeclaw：
```
用户: Bot 只在"技术组"和"产品组"两个群回复消息
```

### Q3: 如何限制 Bot 的使用人员？

**A**:
```
用户: 只有管理员可以使用 Bot
```

### Q4: Bot 消息格式乱码？

**A**: 启用 Card V2 格式：
```
用户: 启用 Card V2 格式
```

### Q5: 如何备份数据？

**A**:
```
用户: 备份 Bot 的所有数据
```

Beeclaw 会导出会话、记忆、配置到备份文件。
