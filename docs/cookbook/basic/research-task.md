# 深度研究任务

> 25分钟学会使用网络工具进行系统化研究

## 场景

你需要了解"2024年电动汽车市场趋势"，用于撰写投资分析报告。传统的搜索方式效率低下，信息碎片化。你希望 Beeclaw 能：

1. **多角度搜索**：从技术、市场、政策等多个维度收集信息
2. **自动抓取关键内容**：从多个来源提取核心数据
3. **生成结构化报告**：整合信息，生成可保存的研究报告

- ✅ 掌握 `web_search` 网络搜索工具

## 常见问题

### Q1: 搜索结果不准确怎么办？

**A**:
1. **优化查询词**: 使用更具体的关键词
   ```bash
   ❌ "汽车"
   ✅ "2024年中国电动汽车销量数据"
   ```

2. **指定时间范围**: 限制在最近
   ```typescript
   web_search({
     query: "...",
     time_range: "month"  // 或 "week"
   })
   ```

3. **调整区域**: 使用正确的 region
   ```typescript
   region: "cn"  // 中国内容
   region: "us"  // 美国内容
   ```

### Q2: 抓取网页内容失败？

**A**: 常见原因和解决方案：

| 错误 | 原因 | 解决方案 |
|------|------|---------|
| `403 Forbidden` | 网站禁止爬虫 | 使用官方 API 或手动复制 |
| `Timeout` | 网络超时 | 重试或更换网络 |
| `Content too large` | 内容超过限制 | 增加 `max_length` 参数 |

### Q3: 深度研究太慢？

**A**: 调整深度级别：

```typescript
// 快速模式（1-2分钟）
depth: "quick"  // 3次搜索，2个来源

// 标准模式（2-3分钟）
depth: "standard"  // 5次搜索，4个来源

// 深度模式（5-10分钟）
depth: "comprehensive"  // 8+次搜索，6+个来源
```

### Q4: 如何引用来源？

**A**: 深度研究报告自动包含来源列表：

```markdown
## 来源

1. [标题](链接)
   - 发布日期: 2024-03-15
   - 权威性: 官方数据
```

引用格式：
```markdown
根据[中国汽车工业协会](链接)的数据，2024年销量...
```

配置定时任务，每周自动研究并更新报告：

```json

      "id": "weekly-research",
```
