## 常见问题

### Q1: Beeclaw 如何保证研究的准确性？

**A**: Beeclaw 会：
- 从多个来源交叉验证
- 引用权威来源
- 标注数据来源和时间
- 你可以要求验证特定信息

### Q2: 研究结果可以更新吗？

**A**: 可以！告诉 Beeclaw：
```
用户: 更新电动汽车市场报告，补充最新的2026年数据
```

### Q3: 如何让研究更深入？

**A**: 指定研究深度：
```
用户: 深度研究"XXX"（深度：comprehensive）
```

**深度级别**:
- `quick` - 快速了解（3次搜索，1-2分钟）
- `standard` - 标准研究（5次搜索，2-3分钟）
- `comprehensive` - 深度分析（8+次搜索，5-10分钟）

### Q4: 研究结果会保存到记忆吗？

**A**: 可以要求保存：
```
用户: 研究完成后的结果也保存到记忆系统，方便以后查询
```
