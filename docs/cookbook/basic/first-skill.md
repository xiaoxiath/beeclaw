# 创建第一个技能

> 5分钟学会通过对话创建自定义技能

## 场景

你希望 Beeclaw 能帮你自动生成每周的工作周报。与其每周重复写，不如创建一个技能，一键生成结构化的周报。

## 目标

- ✅ 通过对话让 Beeclaw 创建技能
- ✅ 测试技能执行
- ✅ 理解如何改进技能

---

## 步骤

### 步骤 1：与 Beeclaw 对话创建技能

直接告诉 Beeclaw 你需要什么：

```
用户: 帮我创建一个周报生成技能，能自动生成本周完成的工作、遇到的问题和下周计划
```

**Beeclaw 会**:
1. ✅ 理解你的需求
2. ✅ 自动创建技能文件
3. ✅ 设计技能内容
4. ✅ 保存到技能库

**预期回复**:
```
Beeclaw: 好的！我帮你创建了一个"周报生成"技能。

技能已保存到: skills/productivity/weekly-report.md

这个技能可以：
- 根据你的工作记录生成结构化周报
- 包含本周完成、遇到问题、下周计划
- 支持多种输出格式

你现在可以说："生成本周周报"来使用这个技能。
```

---

### 步骤 2：测试技能

直接使用自然语言调用技能：

```
用户: 生成本周周报

本周我完成了：
- 完成了用户认证模块
- 修复了3个bug
- 参加了2次团队会议

遇到的问题：
- 数据库查询性能问题，已优化

下周计划：
- 开发权限管理模块
```

**Beeclaw 会**:
1. ✅ 识别你要使用周报技能
2. ✅ 加载技能模板
3. ✅ 整理你的输入
4. ✅ 生成结构化周报

**预期输出**:
```markdown

## 📋 本周完成

1. **用户认证模块开发**
   - 完成了登录、注册、密码重置功能
   - 集成了 JWT 认证机制

2. **Bug 修复**
   - 修复了3个线上bug
   - 提升了系统稳定性

3. **团队协作**
   - 参加了2次技术评审会议

## ⚠️ 遇到的问题

- **数据库查询性能问题**
  - 问题: 查询响应时间过长
  - 解决: 优化了索引
  - 状态: ✅ 已解决

## 🎯 下周计划

1. 开发权限管理模块（RBAC）
2. 编写单元测试

---
*生成时间: 2026-03-14 16:30*
```

1. ✅ 理解你的反馈

## 常见问题

### Q1: 技能创建后存储在哪里？

**A**: Beeclaw 会自动将技能存储在 `skills/` 目录下，你可以：
- 通过 `/skill list` 查看所有技能
- 通过 `/skill get productivity/weekly-report` 查看详情
- Beeclaw 会自动管理技能文件

### Q2: 如何删除不需要的技能？

**A**: 直接告诉 Beeclaw：
```
用户: 删除周报生成技能
```

### Q3: 技能可以共享吗？

**A**: 可以！技能文件是纯文本，你可以：
- 分享给同事（复制文件）
- 导出为 JSON
- 发布到技能市场（未来功能）

### Q4: 如何让技能更智能？

**A**: 持续与 Beeclaw 对话改进：
```
用户: 周报技能需要改进：
1. 自动从 Git 提取本周代码提交
2. 从日历获取会议记录
3. 添加团队协作部分
```
