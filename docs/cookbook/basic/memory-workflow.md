# 记忆管理工作流

> 10分钟学会让 Beeclaw 管理你的知识和记忆

## 场景

你是一个知识工作者，每天接触大量信息。你希望 Beeclaw 能帮你：
- 记住重要的信息和决策
- 快速找到之前的知识
- 自动整理和归档

## 目标

- ✅ 学会与 Beeclaw 对话记录信息
- ✅ 学会通过对话搜索记忆
- ✅ 理解 Beeclaw 如何组织记忆

---

## 步骤

### 步骤 1：让 Beeclaw 记录信息

直接告诉 Beeclaw 你想记住的内容：

```
用户: 记住：我参加了今天的季度规划会议，确定了Q2的3个核心目标：用户增长20%、性能优化30%、新功能上线
```

**Beeclaw 会**:
1. ✅ 理解信息类型（这是近期事件）
2. ✅ 自动分类到 `facts/events`
3. ✅ 提取关键词建立索引
4. ✅ 保存到记忆系统

**预期回复**:
```
Beeclaw: 好的，我帮你记录了这条事件信息：

📝 已记录到: facts/events.md
🏷️ 关键词: 季度规划, Q2目标, 用户增长, 性能优化
📅 时间: 2026-03-14

你随时可以问我关于这次会议的信息。
```

---

### 步骤 2：记录经验教训

```
用户: 记住一个教训：今天因为没做数据备份，浪费了2小时恢复数据，定期备份很重要
```

**Beeclaw 会**:
1. ✅ 识别这是经验教训
2. ✅ 保存到 `facts/lessons`
3. ✅ 提取关键词：备份、数据安全

**预期回复**:
```
Beeclaw: 好的，我帮你记录了这个教训：

📝 已记录到: facts/lessons.md
🏷️ 关键词: 备份, 数据安全, 恢复
💡 提示: 我会在相关场景提醒你注意备份
```

---

### 步骤 3：让 Beeclaw 记住你的偏好

```
用户: 记住：我喜欢简洁的代码风格，不喜欢过度工程化
```

**Beeclaw 会**:
1. ✅ 识别这是用户偏好
2. ✅ 保存到 `facts/preferences`
3. ✅ 在代码相关对话中应用

---

### 步骤 4：搜索记忆

通过自然语言搜索之前的信息：

```
用户: 我之前提到的Q2目标是什么？
```

**Beeclaw 会**:
1. ✅ 搜索关键词 "Q2目标"
2. ✅ 找到相关记录
3. ✅ 返回结果

**预期回复**:
```
Beeclaw: 根据你的记录（2026-03-14），Q2的3个核心目标是：

1. 📈 用户增长 20%
2. ⚡ 性能优化 30%
3. 🚀 新功能上线

这些目标是在今天的季度规划会议中确定的。
```

---

## 常见问题

### Q1: Beeclaw 如何组织我的记忆？

**A**: Beeclaw 自动分类：
- **facts/** - 动态数据（日/周级）：事件、教训、偏好
- **knowledge/** - 稳定知识（月/年级）：职业、家庭、财务

你不需要手动管理，直接对话即可。

### Q2: 记忆会丢失吗？

**A**: 不会，记忆持久化保存：
- 自动保存到文件系统
- 自动备份和压缩
- 可以导出备份

### Q3: 如何删除错误记忆？

**A**: 直接告诉 Beeclaw：
```
用户: 删除刚才记录的错误信息
```

### Q4: 其他人能看到我的记忆吗？

**A**: 不能，记忆存储在本地：
- 文件权限保护
- 不会上传到云端（除非你配置）
- 私密信息安全存储
