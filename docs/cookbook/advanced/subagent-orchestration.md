# 子代理编排

> 20分钟学会让 Beeclaw 并行处理复杂任务

## 场景

你需要完成一个复杂的市场分析任务，包含多个子任务：
1. 搜索技术趋势
2. 收集竞品信息
3. 抓取用户评价
4. 综合生成报告

传统串行执行需要 15 分钟，让 Beeclaw 并行处理可缩短到 5 分钟。

## 目标

- ✅ 学会让 Beeclaw 并行执行任务
- ✅ 理解 Beeclaw 如何自动协调任务
- ✅ 学会让 Beeclaw 综合多个结果

## 步骤

### 步骤 1：简单并行任务

让 Beeclaw 同时搜索多个主题：

```
用户: 同时搜索以下内容：
1. React 19 新特性
2. Vue 3.4 更新
3. Svelte 5 发布时间
```

**Beeclaw 会**:
1. ✅ 识别这是并行任务
2. ✅ 同时启动 3 个子任务
3. ✅ 并行执行搜索
4. ✅ 汇总结果

**执行过程**:
```
🔄 启动并行任务 (3个)...

任务 1: 搜索 React 19 新特性... ✅ (完成 25s)
任务 2: 搜索 Vue 3.4 更新... ✅ (完成 28s)
任务 3: 搜索 Svelte 5 发布时间... ✅ (完成 22s)

✓ 所有任务完成
总耗时: 28s (并行执行，节省 60% 时间)
```

**预期输出**:
```markdown
# 并行搜索结果汇总

## React 19 新特性
- Server Components 稳定版
- useOptimistic Hook
- Actions 统一表单处理

## Vue 3.4 更新
- 响应式系统优化

- 水合错误改进

## Svelte 5 发布时间
- 预计 2024 年中发布
- Runes 新响应式系统
```

## 常见问题

### Q1: Beeclaw 如何决定哪些任务并行？

**A**: Beeclaw 会自动分析：
- 任务之间是否有依赖
- 是否需要前一个任务的结果
- 自动优化执行顺序

你不需要关心技术细节，直接告诉需求即可。

### Q2: 并行任务有数量限制吗？

**A**: Beeclaw 会智能控制：
- 默认最多 3 个任务并行
- 避免过载和冲突
- 自动排队等待

### Q3: 如果某个任务失败了怎么办？

**A**: Beeclaw 会：
- 继续执行其他任务
- 标记失败的任务
- 返回部分结果
- 你可以要求重试失败任务

### Q4: 可以指定执行顺序吗？

**A**: 可以，但通常不需要。Beeclaw 会自动分析依赖关系。如果需要：
```
用户: 按顺序执行：先 A，然后 B，最后 C
```
