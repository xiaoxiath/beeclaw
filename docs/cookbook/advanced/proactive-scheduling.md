# 主动调度系统

> 15分钟学会让 Beeclaw 定时自动工作

## 场景

你希望 Beeclaw 能：
1. 每周五自动生成周报
2. 每天早上提醒今日待办
3. 定期检查重要信息并主动通知你

## 目标

- ✅ 学会让 Beeclaw 创建定时任务
- ✅ 学会让 Beeclaw 主动通知你
- ✅ 学会管理定时任务

---

## 步骤

### 步骤 1：创建简单的定时任务

让 Beeclaw 每天早上提醒你：

```
用户: 每天早上9点提醒我今天的目标
```

**Beeclaw 会**:
1. ✅ 理解定时需求
2. ✅ 创建定时任务
3. ✅ 配置执行时间
4. ✅ 确认任务创建

**预期回复**:
```
Beeclaw: ✅ 已创建定时任务

任务名称: 每日目标提醒
执行时间: 每天 09:00
下次执行: 明天 09:00

我会每天早上9点主动提醒你今天的目标。

需要我立即执行一次测试吗？
```

---

### 步骤 2：创建周报任务

让 Beeclaw 每周五自动生成周报：

```
用户: 每周五下午5点，根据我本周的工作记录自动生成周报并发到我邮箱
```

**Beeclaw 会**:
1. ✅ 创建定时任务
2. ✅ 配置周报生成技能
3. ✅ 设置通知方式
4. ✅ 测试任务

**预期回复**:
```
Beeclaw: ✅ 已创建周报定时任务

任务配置:
- 执行时间: 每周五 17:00
- 任务类型: 生成周报
- 数据来源: 本周工作记录（从记忆系统）
- 通知方式: 邮件发送

下次执行: 本周五 17:00

我已经准备好，会自动从你的记忆中提取本周工作并生成周报。
```

---

```
用户: 查看我所有的定时任务
```

```
   - 执行时间: 每天 09:00

   - 状态: ✅ 活跃

2. **周报自动生成** 📊
   - 执行时间: 每周五 17:00
   - 下次执行: 本周五 17:00
   - 状态: ✅ 活跃

3. **项目进度检查** 🔍
   - 执行时间: 每周一 10:00
   - 下次执行: 下周一 10:00
   - 状态: ⏸️ 暂停

需要修改某个任务吗？
```

---

### 步骤 4：管理定时任务

#### 暂停任务

```
用户: 暂停"每日目标提醒"
```

**预期回复**:
```
Beeclaw: ✅ 已暂停"每日目标提醒"

任务仍然保留，但不会自动执行。
你可以随时说"恢复每日目标提醒"来重新启用。
```

---

#### 修改任务

```
用户: 把周报生成时间改成每周五下午4点
```

**预期回复**:
```
Beeclaw: ✅ 已更新任务时间

任务: 周报自动生成
新时间: 每周五 16:00
下次执行: 本周五 16:00
```

---

#### 删除任务

```
用户: 删除"每日目标提醒"
```

**预期回复**:
```
Beeclaw: ⚠️ 确认删除"每日目标提醒"吗？

这个操作不可恢复。
回复"确认删除"继续，或"取消"保留任务。
```

## 常见问题

### Q1: Beeclaw 必须一直运行吗？

**A**: 是的，Beeclaw 需要保持运行才能执行定时任务。建议：
```
用户: 用 PM2 让 Beeclaw 7x24 小时运行
```

### Q2: 如何设置复杂的时间？

**A**: 直接用自然语言描述：
```
用户: 每个月第一个周一的上午10点
用户: 每季度最后一天下午5点
用户: 每年1月1日零点
```

Beeclaw 会自动理解并配置。

### Q3: 错过了任务执行怎么办？

**A**: Beeclaw 会：
- 记录错过的任务
- 下次启动时提醒你
- 可以要求立即补执行

### Q4: 任务失败了怎么办？

**A**: Beeclaw 会：
- 自动重试（最多 3 次）
- 记录失败原因
- 发送失败通知
- 你可以要求手动执行

### Q5: 可以临时执行任务吗？

**A**: 可以：
```
用户: 立即执行一次"周报生成"
```
