# Beeclaw 主动聊天示例

## 🤖 什么是主动聊天？

Beeclaw 可以在**无需用户触发**的情况下，主动向用户发送消息。这是通过：
- **LLM 生成内容** - 根据用户上下文个性化
- **定时调度** - Cron 或延迟任务
- **自动推送** - 直接发送到飞书

## 📅 场景 1：每日早间问候

### 配置

```json
{
  "name": "每日早间问候",
  "description": "每天早上9点发送问候和日程提醒",
  "cron": "0 9 * * *",
  "taskType": "llm_proactive_chat",
  "taskParams": {
    "prompt": "早上好！现在是北京时间早上9点。

根据用户的日程和目标：
1. 发送一个简短、友好的问候
2. 提醒今天的重要事项
3. 提供1-2条实用建议

保持简洁，不要超过100字。"
  }
}
```

### 效果

**用户收到：**

> 早上好！☀️
>
> 今天有 2 个重要事项：
> 1. **14:00 产品评审会** - 记得准备 Q1 数据
> 2. **18:00 健身** - 今天是腿部训练日
>
> 💡 建议：上午完成代码审查，下午开会前喝杯咖啡提神！

## 🔧 如何创建主动聊天任务

### 方法 1：在飞书中直接说

```
用户：帮我创建一个每天早上9点的问候任务
Bot：好的！我为你创建一个"每日早间问候"任务...

[Bot 自动调用 proactive_schedule 工具]
```

### 方法 2：手动配置

编辑 `data/memory/proactive/schedules.json`：

```json
{
  "schedules": {
    "schedule-xxx": {
      "id": "schedule-xxx",
      "name": "每日早间问候",
      "cron": "0 9 * * *",
      "enabled": true,
      "task": {
        "type": "llm_proactive_chat",
        "params": {
          "prompt": "早上好！..."
        }
      }
    }
  }
}
```

## 💡 最佳实践

### ✅ 应该做的

1. **个性化** - 利用用户上下文
2. **简洁** - 不要超过 150 字
3. **有价值** - 提供实用信息或建议
4. **时机合适** - 避免深夜或工作时间频繁打扰

### ❌ 不应该做的

1. **过度推送** - 每天不超过 3-5 次
2. **内容空洞** - "你好"、"在吗" 这种消息
3. **忽略上下文** - 用户在开会时推送无关内容
4. **递归创建任务** - 在主动消息中再创建任务

## 🎨 高级技巧

### 1. 结合用户偏好

```json
{
  "prompt": "根据用户的偏好（喜欢简洁/详细），调整消息风格...",
  "taskParams": {
    "prompt": "早上好！根据 facts/preferences.md 中的用户偏好：
    - 如果喜欢简洁：一句话问候
    - 如果喜欢详细：提供完整建议"
  }
}
```

### 2. 条件化推送

```json
{
  "prompt": "检查用户今天是否有重要会议。
  如果有：提前提醒
  如果没有：简单问候",
  "taskParams": {
    "prompt": "读取 facts/schedule.md..."
  }
}
```

### 3. 结合技能

```json
{
  "taskType": "run_skill",
  "taskParams": {
    "skillName": "smart-greeting",
    "prompt": "根据天气、日程、用户状态生成智能问候"
  }
}
```

## 📊 查看所有主动任务

```bash
# 查看所有定时任务
cat data/memory/proactive/schedules.json | jq '.schedules | keys'

# 查看特定任务
cat data/memory/proactive/schedules.json | jq '.schedules["schedule-xxx"]'

# 查看任务执行历史
tail -f logs/beeclaw-out.log | grep "llm_proactive_chat"
```
