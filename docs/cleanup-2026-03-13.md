import { retryAICall } from '../../infra/resilience/retry';

## 🔧 迁移指南

### 从 skill_create/skill_update 迁移到 skill_ensure

**旧代码**:
```typescript
// 创建技能
executeSkillTool('skill_create', {
  name: 'my-skill',
  description: 'My skill description',
  content: '# My Skill\n\nInstructions...',
  tags: ['category'],
});

// 更新技能
executeSkillTool('skill_update', {
  name: 'my-skill',
  description: 'Updated description',
});
```

**新代码**:
```typescript
// 创建或更新技能（自动判断）
executeSkillTool('skill_ensure', {
  name: 'my-skill',
  description: 'My skill description',
  content: '# My Skill\n\nInstructions...',
  tags: ['category'],
  triggers: ['trigger phrase'],  // 可选
  dependsOn: ['other-skill'],     // 可选
});
```

**优势**:
- ✅ 一个工具处理创建和更新
- ✅ 自动检测技能是否存在
- ✅ 新技能会触发 skill-creator 工作流（质量保证）
- ✅ 现有技能直接更新
- ✅ 更简洁的 API
