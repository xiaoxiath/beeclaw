## 🎨 文档设计原则

1. **DRY** - 单一信息源，避免重复
2. **用户优先** - 从用户角度组织
3. **渐进式** - 从简单到复杂
4. **可发现性** - 地图 + 导航 + 交叉引用
5. **可维护性** - 版本 + 变更日志 + 规范
6. **国际化** - 术语表 + 翻译规划
