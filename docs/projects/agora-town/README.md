# Agora Town - AI Agent 虚拟世界

> 一个基于多智能体协作的虚拟世界项目

## 项目概述

Agora Town 是一个创新的 AI Agent 虚拟世界项目，探索多智能体协作、自主决策和动态环境交互的可能性。

## 核心文档

- [产品需求文档 (PRD)](./prd.md) - 项目愿景、用户场景、功能需求
- [MVP 实施计划](./mvp-plan.md) - 最小可行产品的开发路线图

## 项目状态

🚧 **实验性项目** - 目前处于概念验证阶段

## 技术栈

- **AI 框架**: Beeclaw (多智能体协作)
- **前端**: React + TypeScript
- **后端**: Node.js + WebSocket
- **数据库**: PostgreSQL + Redis

## 快速开始

```bash
# 克隆项目
git clone https://github.com/beeclaw/agora-town.git

# 安装依赖
bun install

# 配置环境变量
cp .env.example .env

# 启动开发服务器
bun run dev
```
